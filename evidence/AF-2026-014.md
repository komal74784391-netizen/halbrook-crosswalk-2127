# Audit Finding AF-2026-014

- **Engagement:** FY26 data-handling control review
- **Date:** 2026-02-14
- **Site:** Denver data centre
- **Retired standard referenced:** Halbrook Data Handling Standard, Edition 3.1 (retired 31 December 2025)

## Finding

The document reviewed cites the retired provision below:

> Encryption at rest using AES-256 is required for all Confidential data stores.

Cited provision: **Clause 6(1)**

**Reviewer observation:** The storage build standard quotes the retired sentence above. The build standard is due for its next scheduled review.
