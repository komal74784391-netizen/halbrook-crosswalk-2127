# Audit Finding AF-2026-028

- **Engagement:** FY26 data-handling control review
- **Date:** 2026-02-28
- **Site:** Supplier assurance, Amsterdam
- **Retired standard referenced:** Halbrook Data Handling Standard, Edition 3.1 (retired 31 December 2025)

## Finding

The document reviewed cites the retired provision below:

> Suppliers must maintain an information security management system certified to ISO/IEC 27001 or an equivalent standard.

Cited provision: **Supplier Code of Conduct, section 5.4**

**Reviewer observation:** The supplier questionnaire quotes the Supplier Code of Conduct. That document is outside the scope of the Data Handling Standard crosswalk.
